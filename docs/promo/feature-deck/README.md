# PZManager 功能介绍 · HTML 幻灯片

一个可以**直接演示**、也可以**把自己的截图拖进去**的单页 PPT。没有构建步骤、没有外部依赖，
双击 `index.html` 就能播（建议 Chrome / Edge / WebView2）。

## 打开与播放

- 双击 `index.html`；或在本目录执行 `python -m http.server 8000` 后访问 `http://localhost:8000`。
- `←` `→` / 空格 翻页，`Home` / `End` 跳首尾，`F` 全屏，`H` 看快捷键。
- 地址栏支持定位：`index.html#4` 直接打开第 4 页。

## 截图规格（重要）

内置示例与画框都按**应用的最小窗口尺寸 `970 × 564`** 对齐（`src-tauri/tauri.conf.json` 的
`minWidth` / `minHeight`），画框比例也是 `970 / 564`，`object-fit: contain`，不会裁掉标题栏或面板。

推荐流程：

1. 打开 PZManager，把窗口拖到最小（不能再缩小即可，就是 970 × 564）；
2. **等 5 秒**再截图——四季壁纸的光影、亚克力模糊、面板动画都要一点时间稳定，
   刚打开就截容易拍到半透明的中间帧；
3. 用 `Win + Shift + S` 框选窗口（或 `Alt + PrtScn`），拖进对应画框。

用大窗口截图也能放，画框会等比缩放并留一点黑边。

## 放截图（两种方式，任选）

**A. 直接拖进去（推荐，最快）**
点画框选文件，或把图片直接拖到画框里。拖入的图以 data URL 存在页面里，导出时自动内联。

**B. 按文件名放到 `shots/`**
画框里会显示它期待的文件名，放进去刷新即可：

| 画框 | 文件名 | 建议截什么 |
| --- | --- | --- |
| 启动页（第 2 页） | `01-launch.jpg` | 启动页整窗 |
| 外观（第 3 页） | `02-menus.jpg` | 打开「启动设置」+ 背景菜单 |
| 设置（第 8 页） | `03-settings.jpg` | 设置 › 通用（对比度、模糊度） |
| 模组管理（第 4 页） | `04-mods.jpg` | JAR 或 Lua 列表 |
| 光影与资源（第 5 页） | `05-resources.jpg` | 光影 / 资源中心 |
| 创意工坊（第 6 页） | `06-workshop.jpg` | 工坊列表或详情 |
| 截图管理（第 7 页） | `07-shots.jpg` | 截图管理页 |

> 目前 `01`–`03` 是内置示例（用应用的 Web 渲染层按 970×564 截的，版式与真实窗口一致）；
> `04`–`07` 还是空画框，等你用真机截图替换。
> 设置页那张把「字体对比度」调到了 50%，否则亮壁纸上的说明文字偏淡——这也顺带演示了这个功能。

## 导出

- **`E` → 单文件 HTML**：下载一份 `pzmanager-feature-deck.html`。拖进去的截图会内联，
  可以直接发给别人；如果还有相对路径的图（`shots/` 里没替换的），会把 `shots/` 目录一起发。
- **打印成 PDF**：`Ctrl + P` → 目标「另存为 PDF」→ 布局「横向」→ 勾选「背景图形」。
  每页一张幻灯片（1600×900），适合当真正的 PPT / 预览图用。

## 改文案

全部内容在 `index.html` 里，一个 `<section class="slide">` 就是一页：

- `.slide--cover`：封面 / 结尾那种居中版式
- `.slide--split`：左文右图（截图页都用这个）
- `.slide--cards`：三栏卡片（技术底座）

改 `<h2>`、`.lead`、`.bullets li` 即可；配色、字号和截图比例（`--shot-ratio`）都在文件顶部的
`:root` 与样式区里。
