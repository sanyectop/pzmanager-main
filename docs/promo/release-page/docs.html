文档中心

从安装到进阶用法,这里覆盖 PZManager 每个功能的说明与常见问题的排查方法。

快速上手

环境要求

  • Windows x64:游戏、启动器与覆盖层组件必须同为 64 位。
  • Steam 版 Project Zomboid:启动器依赖 Steam 环境探测游戏与创意工坊内容。
  • 建议分辨率 1280×720 及以上。

安装

  1. 从 下载页 获取最新版(GitHub Releases 或 123 云盘)。
  2. 解压到你喜欢的目录,运行 PZManager.exe。
  3. 首次启动时,程序会自动探测 Steam 与游戏路径:优先读取注册表,再回退到 Steam 的 libraryfolders.vdf 与 appmanifest 文件,多级回退确保各种安装方式都能找到。
提示:如果探测失败,请确认 Steam 已安装并且 Project Zomboid 已至少启动过一次(存在有效的库存清单文件)。

启动游戏

账户面板

启动页左下角显示 Steam 头像与 Persona 名。点击账户名可以隐藏/显示(用两条短横线遮挡),状态会被记住。

游戏内存

  • 范围从 1 GB 起,以 512 MB 步进,上限为系统物理内存。
  • 8 GB 处标有「推荐」,16 GB 处标有「参考线」;超过 16 GB 时会显示不稳定警告(游戏本身在大内存下可能出问题)。
  • 拖动滑块松手后自动保存,后端会再次校验,防止写入非法值。

启动参数

在启动详情弹层里逐条编辑 Java 启动参数,可增删。默认参数为 -agentlib:zbNative --(配合 ZombieBuddy 模组加载器使用,请勿随意删除)。

启动与停止

点击「启动游戏」后,按钮会进入 3 秒冷却并开始检测游戏进程;窗口就绪后按钮变为「停止游戏进程」。游戏自行退出时状态自动复位。

启动背景

启动设置弹层里可以选择内置背景、导入的自定义图片,或创意工坊模组自带的 title*.png 背景(四宫格拼接)。选中工坊背景时会显示来源模组信息。

启动时长

右下角显示「本次启动 xx.x s」,有历史记录时会显示与上次的差值,方便验证优化效果。

支持库与模组

支持库

「支持库」页面集中管理三项支持组件,每行是一张可折叠卡片,显示名称、一句话说明与状态标签:

组件作用说明
ZombieBuddy 模组加载器 JAR 模组的前置。安装入口在 设置 › 模组加载器,安装时会自动复制 DLL/JAR 并写入三处启动配置。
PZ Optimization 游戏优化 一键安装 / 更新 / 卸载,按 revision 比对判断是否可更新。
Viewpoint 3D 3D 模组配置 需要两个工坊模组全部订阅(Project Viewpoint、ZombieBuddy)后才能一键配置。

Lua 模组

「模组管理 › Lua」里可以调整加载顺序(依赖前置)、批量启用/禁用。顺序即生效优先级。

JAR 模组

「模组管理 › JAR」依赖 ZombieBuddy。启动器会扫描模组注解、分级提示冲突,由你逐个审批启用。

模组预设

把当前「Lua 加载顺序 + JAR 启停状态」保存为一个预设,之后一键切换整套模组组合,适合在不同整合包之间来回切换。

资源中心

创意工坊

「资源中心 › 创意工坊」直接浏览 Steam 创意工坊:支持排序、按时间/标签筛选、搜索与分页,结果有缓存加速。在列表里右键打开模组详情,介绍文本(BBCode)会按段自动翻译。

光影下载

「资源中心 › 光影下载」检索光影资源:Modrinth 优先、CurseForge 兜底、必要时走镜像回退。下载任务进入全局任务中心后台进行,不阻塞界面。

开发者新闻

「资源中心 › 开发者新闻」拉取 Steam 官方新闻动态,翻译按 15 条一批进行,正文与标题都可以切换原文对照。

任务中心

标题栏右侧的「任务」按钮打开任务中心,所有后台下载的进度集中在这里查看。

截图与光影

截图管理

集中展示 Viewpoint 3D 截图,支持列表浏览与预览,选中即可复制到剪贴板,方便直接粘贴分享。

光影管理

把光影 ZIP 包拖进窗口(或点击选择文件)即可导入,不会覆盖同名文件;支持删除、设置图标与搜索词。

游戏内覆盖层

启动游戏时,PZManager 会自动向游戏进程注入覆盖层组件(Hook OpenGL),在游戏加载阶段叠加显示进度界面,替代漫长的黑屏等待。

  • 覆盖层会话与启动流程绑定:游戏窗口就绪后开始工作,游戏退出或点击「停止游戏进程」后自动移除。
  • 注入原理、停止条件与排错表见仓库内的《覆盖层注入文档》(开发者文档)。
注意:覆盖层依赖 64 位环境。若游戏、启动器位数不一致,覆盖层不会生效,但不影响游戏本身启动。

设置详解

分类主要内容
通用 开发者模式(显示注入方法、模组标签、冲突分析与详细通知)、翻译语言、字体对比度、界面模糊度(亚克力/毛玻璃强度,0 为关闭)。
翻译器 开发者新闻与创意工坊说明的翻译行为设置。
控制台 启动时长记录查看、覆盖层会话调试。
下载器 下载并发、镜像偏好等下载行为设置。
模组加载器 ZombieBuddy 的安装与管理。
启动 内存清理(静默阈值 + 启动时清理一次)、极速启动(实验性)。
关于「极速启动」:基于 JVMTI 的实验性功能,链路已打通,但游戏内仍有已知崩溃风险,追求稳定请勿开启。

常见问题

检测不到 Steam / 游戏?

确认 Steam 已正常登录安装,且 Project Zomboid 已安装并至少启动过一次。启动器通过注册表 → 库文件夹 VDF → 应用清单 ACF 三级回退探测,一般安装方式都能覆盖。

JAR 模组页面不可用?

JAR 模组管理依赖 ZombieBuddy 模组加载器,请先在 设置 › 模组加载器 完成安装。

Viewpoint 3D 一键配置按钮是灰的?

需要先在 Steam 创意工坊订阅全部两个模组:Project Viewpoint、ZombieBuddy,订阅后即可点击。

内存滑块拉到 16 GB 以上出现警告?

这是预期行为。Project Zomboid 在超大内存分配下自身可能不稳定,警告只是提醒,仍可继续保存。

游戏内没有出现覆盖层?

确认游戏与启动器都是 64 位;确认没有被杀毒软件拦截注入组件。更多排错步骤见覆盖层文档。

工坊 / 光影下载失败或很慢?

下载链路会自动尝试镜像回退,请检查任务中心里的具体报错;网络环境受限时建议稍后重试或切换网络。

极速启动后游戏崩溃?

极速启动目前是实验性功能,存在已知崩溃风险,请在 设置 › 启动 关闭后重试。
