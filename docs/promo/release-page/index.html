Project Zomboid 桌面启动器 + 模组管理器——一键启动、模组与光影管理、创意工坊浏览下载、游戏内加载覆盖层,一个应用全搞定。

功能一览

不只是启动器,更是 Project Zomboid 的全套桌面工具箱。

一键启动

自动探测 Steam 环境与游戏路径,内存上限、启动参数、启动背景都在一页调好,启动时长自动记录并与上次对比。

模组管理

Lua 与 JAR 模组统一启停、依赖前置、冲突分析,还能把模组组合保存为预设,一键切换整合包。

资源下载

直接浏览 Steam 创意工坊,光影资源从 Modrinth / CurseForge 检索下载并自动镜像回退,进度收进全局任务中心。

新闻翻译

开发者动态与创意工坊说明自动翻译成中文,更新公告、模组介绍第一时间看懂。

截图与光影

Viewpoint 3D 截图集中预览、一键复制到剪贴板;光影包拖拽导入、随手管理。

游戏内覆盖层

注入 DLL + Hook OpenGL,在游戏加载时叠加进度界面,等待不再是黑屏干瞪眼。

界面一览

亚克力质感的深色界面,背景、模糊度、字体对比度都可以随喜好调整。
