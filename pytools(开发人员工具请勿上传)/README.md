# pytools

开发用 Python 小工具，不属于应用本体。

## ui_copy_editor.py — UI 文案查看 / 修改

扫描前端（`src/**/*.{ts,tsx}`）和后端（`src-tauri/src/**/*.rs`）里所有含中文的
文字描述（字符串字面量、JSX 文本节点），在浏览器里按文件分组展示，支持搜索、
按文件过滤和手动修改；保存时写回源码原位置，并在 `backups/<本次运行>/` 自动备份。

```cmd
python pytools\ui_copy_editor.py
```

启动后打开 http://127.0.0.1:10199 。

- 三类文案：`string`（引号字符串）、`jsx`（单行 JSX 文本）、`jsx-block`（独占一行的 JSX 文本）；注释里的中文不算。
- **函数大纲**：像 VSCode 的大纲一样解析每个文件的函数 / 组件 / 类方法 / `useEffect` 等结构（Rust 侧是 `fn` / `impl` / `mod`），文案按「文件 › 所在函数」两级分组展示，长文件的文案不再混在一起。
- 保存前会校验原文仍在原位置，源码已被改动则拒绝并提示刷新。
- JSX 文本不允许写入 `< > { }`；暂不支持多行文案。
- 备份目录 `pytools/backups/` 是工具运行产物，不入库可随时删除。
